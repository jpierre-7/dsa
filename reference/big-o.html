Rules

  1. Count steps, as a function of n, the input size. Assume the worst case unless it's stated otherwise.
  2. Keep the dominant term: 3n² + 5n + 100 → O(n²).
  3. Drop constants: 2n, n/2 → O(n).
  4. One loop after another adds: n + n → O(n).
  5. A loop inside a loop multiplies: n × n → O(n²).
  6. Watch for hidden loops. A single built-in call can be O(n) (see the table).

The fix, in one line

# O(n²): `in` on a list inside a loop
hits = [x for x in a if x in b]

# O(n): build a set once (O(n)), then each lookup is O(1)
b_set = set(b)
hits = [x for x in a if x in b_set]
