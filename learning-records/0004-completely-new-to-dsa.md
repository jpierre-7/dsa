# Completely new to DSA: zero prior knowledge

Corrects [[0001-starting-point]]. The user is a comfortable Python programmer but has *no* prior DSA exposure. "Fuzzy" was the wording of the option they picked in the intake question, not their own description. After Lesson 1 they said it assumed too much, and that some explanations didn't stick.

**Evidence:** Lesson 1 quiz 4/5 on the first attempt. Explain-back: Q1 correct (spotted the hidden loop). Q2 couldn't connect the exercise's set fix back to the opening example. Q3 no idea: that question went beyond what the lesson taught.

**Implications:** define every term on first use, give a concrete example before any rule, write shorter lessons, and ask explain-back questions only about what was taught. Before Lesson 2, re-check that the set fix transfers to a new context.
